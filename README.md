# 🍕 Power BI - Pizza Sales Dashboard

## Description

Ce projet est un tableau de bord interactif réalisé avec Power BI, permettant d’analyser les ventes de pizzas sur une période d'un an.

C’est un projet d'apprentissage réalisé à partir d'un tutoriel proposé par la chaîne YouTube [Data Tutorials][(https://www.youtube.com/@datatutorials1)], qui a également fourni les données.

---

## Objectifs du projet

- Développer mes compétences sur Power BI
- Manipuler des données issues de requêtes SQL
- Créer des KPI et visualisations interactives
- Réaliser un storytelling autour des ventes de pizzas

---

## Données utilisées

Les données proviennent d’un fichier SQL contenant les ventes de pizzas :
- Commandes
- Quantité vendue
- Montant total des ventes
- Catégorie et taille des pizzas
- Date et heure des commandes

---

## Indicateurs clés (KPI)

- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

---

## Visualisations principales

- Analyse quotidienne et mensuelle des ventes
- Répartition des ventes par catégorie et taille de pizza
- Top 5 des pizzas les plus vendues
- Bottom 5 des pizzas les moins vendues
- Tendances et comportements d'achat
